## 📖 Overview

**Queen of Sheba Highland Estate Co.** (`Sheba Estates`) is an artisanal luxury brand and international exporter established in the volcanic cradle of the Ethiopian highlands, overlooking **Lake Tana** and the headwaters of the **Blue Nile**. 

This web application represents the estate’s digital flagship: a synthesis of **heritage storytelling**, **ultra-high-end editorial design**, **interactive cultural education**, and a **frictionless specialty e-commerce engine**.

Engineered from the ground up to embody quiet luxury, the application showcases the estate's **Four Botanical Diamonds** alongside B2B green coffee export catalogs, multi-currency purchasing, generational agroforestry documentation, and direct connections to global trade hubs across **Bahir Dar**, **San Marino**, **Ajman**, and **New York**.

## 💎 The Four Botanical Diamonds

At elevations between **1,800 and 2,250 meters above sea level**, the unique convergence of equatorial sun, mineral-rich volcanic red clay, cool highland nights, and mist-fed canopies yields four botanical masterpieces of extraordinary concentration:

| # | Botanical Diamond | Native Title | Varietal / Classification | Elevation | Flavor Profile & Key Characteristics |
|---|---|---|---|---|---|
| **01** | **Gesha / Zege Coffee** | `ዘጌ ቡና` | *Coffea Arabica* (Wild Heirloom & Gesha) | 1,850 – 2,150 MASL | Jasmine blossom, bergamot citrus, ripe stone peach, raw highland honey finish. Sun-dried on raised African cedar beds. |
| **02** | **Negin Saffron** | `ንጉሥ ኩርኩም` | *Crocus Sativus* (Super Negin Grade A) | 1,950 – 2,250 MASL | Earthy honey, warm dried hay, crocin coloring metric > 250 (exceeds ISO Category I). Hand-plucked at pre-dawn mist. |
| **03** | **Highland Vanilla** | `የደጋ ቫኒላ` | *Vanilla Planifolia* (Bourbon Highland) | 1,800 – 1,980 MASL | Rich creamy vanillin (2.0%–2.4%), dark caramel, dried fig. 16–20cm supple black pods conditioned in wood sweating cellars. |
| **04** | **Highland Macadamia** | `የደጋ ማካዳሚያ` | *Macadamia Integrifolia & Tetraphylla* | 1,800 – 2,100 MASL | Velvety sweet butter, delicate crisp crunch, >74% healthy oil content. Cultivated on terraced hillside regenerative agroforests. |

## ✨ Core Features

### 🛍️ 1. Dynamic Luxury E-Commerce Engine
- **Slide-out Cart Drawer**: Accessible universally across the application with instant animated open/close states.
- **Dual-Currency Converter**: Real-time toggling between **EUR (€)** and **USD ($)** with automated price recalculation.
- **Quantity & Lot Management**: Granular adjustments, quick removal, empty state animations, and subtotal threshold calculations.
- **VIP Promo Voucher Engine**: Built-in promotional validation codes (e.g., `SHEBA10` for 10% welcome discounts, `HIGHLAND15` for 15% connoisseur privileges).
- **Direct WhatsApp & Concierge Checkout**: Seamless handoff of pre-filled shopping carts directly into WhatsApp or personal concierge inquiries.

### ☕ 2. Interactive Ethiopian Coffee Ceremony Experience
- Embedded multi-stage cultural walkthrough of the ancestral **Abol, Tona, and Baraka** brewing ritual.
- Step-by-step interactive tabs highlighting roasting raw green cherries, Frankincense aromatherapy, mortar pounding, and clay *Jebena* decanting.
- Amharic terminology glossary with audio-visual cues and ceremonial etiquette guidelines.

### 📦 3. B2B Wholesale Green Coffee Matrix
- Interactive wholesale procurement catalog for international green coffee importers, roasters, and specialty brokers.
- Full micro-lot specifications covering 8 world-renowned Ethiopian origins:
  - **Kochere** (Gedeo) • **Bonga** (Kaffa Forest) • **Kenbata** (Hadiya) • **Benchimaji** (Bench Maji)
  - **Illubabor** (Oromia) • **Mizan Tepi** (Bench Maji) • **Anderacha** (Sheka) • **Gesha Highlands**
- Packaging formats: **50kg grainpro bags**, **60kg jute sacks**, and **1 Ton consolidated container pallets**.

### 🌿 4. Four Pillars of Regenerative Sustainability
- Deep educational interface demonstrating the estate’s closed-loop agroforestry system:
  1. **Sustain the Soil**: 100% recycling of coffee pulp, saffron stalks, and macadamia husks into active compost.
  2. **Canopy & Biodiversity Protection**: Poly-culture under 20+ native legacy shade tree species sheltering endemic birdlife and native wild bees.
  3. **Water Stewardship**: Gravity-fed drip micro-irrigation and zero-discharge natural sun-drying protecting the Lake Tana / Blue Nile watershed.
  4. **Community Empowerment**: Generational agronomy workshops, distribution of certified macadamia seed stock, and seasonal economic stability.

### 🌐 5. Global Presence & Direct Trade Infrastructure
- Interactive location directory showcasing the four international hubs:
  - **Bahir Dar, Ethiopia** 🇪🇹 — Estate cultivation, harvesting, wet & dry mill processing
  - **Serravalle, Rep. of San Marino** 🇸🇲 — European distribution & continental trade relations
  - **Ajman, United Arab Emirates** 🇦🇪 — Middle East & Gulf regional logistics hub
  - **New York, United States** 🇺🇸 — North American sourcing & corporate partnerships
- Direct contact triggers: One-click phone calling, WhatsApp direct chat, and encrypted inquiry dispatches.

## ⚡ Technical Architecture

- **React 18.3.1**: Modern functional components utilizing custom hooks, `Context API`, and memory-efficient renders.
- **TypeScript 5.5**: Rigorously typed interfaces for all botanical models, products, office locations, and shopping cart payloads.
- **Tailwind CSS 3.4**: Fine-tuned design token system featuring bespoke color palettes, fluid typography, glassmorphism, and responsive breakpoints.
- **Vite 5.4**: Instant Hot Module Replacement (HMR) during development and tree-shaken, chunk-optimized production asset generation.
- **Lucide Icons**: Cohesive, lightweight stroke iconography maintaining visual unity across all components.
- **Zero Heavy External Dependencies**: Built without heavyweight UI bloat—optimized for rapid Time-to-Interactive (TTI) and fast global CDN distribution.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed on your machine:
- **Node.js**: `v18.0.0` or higher (LTS recommended)
- **npm**: `v9.0.0` or higher (or `pnpm` / `yarn`)
- **Git**: For version control

### 1. Clone the Repository

```bash
git clone https://github.com/jonnahjr/shebaestates.git
cd shebaestates
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Launch Development Server

```bash
npm run dev
```

The application will launch locally at:
```
http://localhost:5173/
```

### 4. Build for Production

Compile and bundle optimized static assets:

```bash
npm run build
```

The production-ready bundle will be emitted to the `dist/` directory.

### 5. Preview Production Build

Locally verify the compiled distribution bundle:

```bash
npm run preview
```
